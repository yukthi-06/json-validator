# User Prompt

Create a complete Android application in **Java (NOT Kotlin)** named **"JSON Validator"**.

## Objective

Develop an Android app that validates JSON files for syntax correctness. The user should be able to select either:

1. A single JSON file
2. A folder containing multiple JSON files

After selection, the user clicks a **"Start Validation"** button, and the app validates all JSON files found.

---

## Technology Requirements

* Language: Java only
* Minimum SDK: API 24 or higher
* Target SDK: Latest stable
* Android Studio project
* Material Design UI
* Use Android Storage Access Framework (SAF) for file/folder selection
* Use a robust JSON parser such as:

  * org.json
  * Gson
  * Jackson
* Follow MVVM or clean architecture where practical
* Include all required permissions and manifest entries
* Generate complete source code

---

### App Name

JSON Validator

At the top:

* Application title: "JSON Validator"

Selection section:

* Button: "Select JSON File"

Display selected path beneath the buttons.

Validation section:

* Button: "Start Validation"

Results section:

At the bottom of the screen:

* A scrollable ListView or RecyclerView
* Columns:

  * File Path
  * Status

---

## Validation Behavior

### Single File Mode

When a JSON file is selected:

* Validate the selected file.
* Display one result row.

### Folder Mode

When a folder is selected:

* Recursively scan all files.
* Validate every file ending with:

  * .json
* Ignore non-json files.

Display one result row per file.

---

## Validation Rules

A file is VALID when:

* JSON syntax is correct.
* Root can be:

  * Object
  * Array

Status should display:

OK

Example:

File:
storage/emulated/0/data/customer.json

Status:
OK

---

## Invalid JSON Handling

When JSON parsing fails:

Extract and display:

* File name
* Full file path
* Line number
* Error message

Example status:

ERROR - Line 17 - Missing ',' delimiter

Example row:

Path:
storage/emulated/0/data/customer.json

Status:
ERROR - Line 17 - Missing ',' delimiter

---

## Error Line Detection

Implement logic to:

* Parse parser exception messages
* Extract line number whenever available
* If unavailable, display:

ERROR - Unknown line - <message>

---

Create a ResultItem model:

## UI Color Coding

For valid files:

## Performance

For folder validation:

* Run validation on a background thread using:

  * ExecutorService
  * WorkManager
  * Async processing

Do not block the UI thread.

Show a ProgressBar while validation is running.

Disable Start Validation button during processing.

Re-enable when completed.
