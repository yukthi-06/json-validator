# User Prompt

Create a complete Android application in **Java (NOT Kotlin)** named **"JSON Validator"**.

## Objective

Develop an Android app that validates JSON files for syntax correctness. The user should be able to select either:

1. A single JSON file
2. A folder containing multiple JSON files

After selection, the user clicks a **"Start Validation"** button, and the app validates all JSON files found.

---

## Technology Requirements

* Language: Java only
* Minimum SDK: API 24 or higher
* Target SDK: Latest stable
* Android Studio project
* Material Design UI
* Use Android Storage Access Framework (SAF) for file/folder selection
* Use a robust JSON parser such as:

  * org.json
  * Gson
  * Jackson
* Follow MVVM or clean architecture where practical
* Include all required permissions and manifest entries
* Generate complete source code

## Validation Behavior

### Single File Mode

When a JSON file is selected:

* Validate the selected file.
* Display one result row.

### Folder Mode

When a folder is selected:

* Recursively scan all files.
* Validate every file ending with:

  * .json
* Ignore non-json files.

Display one result row per file.

---

## Validation Rules

A file is VALID when:

* JSON syntax is correct.
* Root can be:

  * Object
  * Array

Status should display:

OK

Example:

File:
storage/emulated/0/data/customer.json

Status:
OK

When JSON parsing fails:

Extract and display:

* File name
* Full file path
* Line number
* Error message

Example status:

ERROR - Line 17 - Missing ',' delimiter

Example row:

# Implementation Plan - JSON Validator Android App

## User Review Required

> [!IMPORTANT]
> The app will be written fully in Java 8+ targeting Android API level 24 (minSdkVersion) up to API 34 (targetSdkVersion). We will use Google Gson for parsing JSON and locating exact exception details since Gson includes precise line/column numbers in its exceptions.

## Proposed Changes

We will create a structured Android Studio project layout within the repository root:
- Create `settings.gradle` (modify existing) and `build.gradle` (modify existing).
- Create `app` module containing `app/build.gradle`, `app/src/main/AndroidManifest.xml`, resources, layouts, and Java sources under the package `com.example.jsonvalidator`.

### 1. Build & Project Configurations
- **Modify** `settings.gradle` to set name to "JSON Validator" and ensure `app` module is included.
- **Modify** `build.gradle` (root) to configure Android gradle plugin.
- **New** `app/build.gradle` with Android configurations and dependencies:
  - `androidx.appcompat:appcompat:1.6.1`
  - `com.google.android.material:material:1.12.0`
  - `androidx.constraintlayout:constraintlayout:2.1.4`
  - `androidx.lifecycle:lifecycle-viewmodel:2.6.2`
  - `androidx.lifecycle:lifecycle-livedata:2.6.2`
  - `com.google.code.gson:gson:2.11.0`
  - `androidx.documentfile:documentfile:1.0.1` (to traverse folders recursively under Storage Access Framework)

### 2. Layout & Resources
- **New** `app/src/main/res/layout/activity_main.xml`:
  - Title card styled with Material Design.
  - Buttons for file and folder picker.
  - Selected Path TextView.
  - "Start Validation" MaterialButton.
  - Horizontal cards/layout displaying summary: Total, Valid, Invalid files.
  - Indeterminate ProgressBar (initially hidden).
  - RecyclerView for results.
- **New** `app/src/main/res/layout/item_result.xml`:
  - CardView or ConstraintLayout displaying the file path/URI and validation status with appropriate color coding (green for OK, red for Error).
- **New** `app/src/main/res/values/colors.xml`, `strings.xml`, `themes.xml`:
  - Standard themes inheriting from `Theme.Material3.DayNight.NoActionBar`.
  - Rich color palette (vibrant blues, dark mode friendly shades, green for success, red for errors).

### 3. Application Source Code
We will structure the source code inside `app/src/main/java/com/example/jsonvalidator`:
- **New** `model/ResultItem.java`:
  - Fields: `filePath` (or display name), `status`, `isValid`, `lineNumber`, `errorMessage`.
- **New** `utils/JsonValidator.java`:
  - Validates a raw JSON string content.
  - Validates that the root structure is either a `JsonObject` or `JsonArray`.
  - Tries to parse using Gson `JsonParser.parseString`.
  - Captures `JsonSyntaxException` and extracts the line number using a regex pattern. Returns a structured validation result.
- **New** `adapter/ResultAdapter.java`:
  - Binds the list of `ResultItem`s to the RecyclerView.
  - Colors the status text dynamically (success green: `#2E7D32`, error red: `#C62828`).
- **New** `viewmodel/ValidationViewModel.java`:
  - Holds `LiveData` lists of `ResultItem`s, summary stats, loading state, and selected URI path.
  - Performs recursive folder scans and validations asynchronously using a Java `ExecutorService` (background thread pool) to avoid blocking the main UI thread.
  - Reads data from Uri streams using the Android content resolver.
- **New** `MainActivity.java`:
  - Implements UI listeners.
  - Uses `ActivityResultLauncher` with `StartActivityForResult` or `OpenDocument` / `OpenDocumentTree` to allow selection of files/directories.
  - Observes ViewModel LiveData to update UI elements (stats, progress bar, lists, button enabled/disabled states).
